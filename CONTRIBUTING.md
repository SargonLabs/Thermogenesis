# Contributing to Thermogenesis

Thank you for your interest in contributing. This project is in early R&D and contributions are welcome.

## Licensing

- **Firmware** (`firmware/`): GPL-3.0. Your contributions will be licensed under GPL-3.0.
- **Hardware** (`hardware/`, `enclosure/`): CERN-OHL-S-2.0. Your contributions will be licensed under CERN-OHL-S-2.0.
- **Documentation** (`docs/`): CC-BY-SA-4.0.
- **Backend** (`backend/`): AGPL-3.0.

## Getting started

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/your-feature`)
3. Commit your changes
4. Push to your fork
5. Open a pull request

## Generative AI policy

If you use generative AI tools (LLMs, code assistants) to produce code or documentation contributed to this project, you must disclose this in your commit message or pull request description. Include the model used and a summary of how it was used. See [NLnet's GenAI policy](https://nlnet.nl/foundation/policies/generativeAI/) for background.

## Code style

- Firmware: C++, PlatformIO build system
- Backend: Docker Compose deployment
- Documentation: Markdown
